What to look for

  • The dot is placed instantly on every pointer event, so it never lags.
  • The ring eases toward the dot each frame, which reads as weight.
  • Hover grows the ring to 56px and turns it red over anything clickable.
  • Press and hold shrinks it slightly — that is the scale property, not a size change.
  • Toggle the theme up top: the cursor darkens so it stays visible on white.

How it works

Position comes from mousemove; the ring's easing runs on requestAnimationFrame and is frame-rate independent, so it feels identical at 60Hz and 144Hz. The loop stops itself once the ring settles, and every layer uses translate3d and pointer-events: none — it can never block a click.

Touch and keyboard

The whole effect is wrapped in @media (hover: hover) and (pointer: fine), so touch devices never load a cursor layer they cannot use. Keyboard users keep the native focus ring — nothing is hidden from them.
